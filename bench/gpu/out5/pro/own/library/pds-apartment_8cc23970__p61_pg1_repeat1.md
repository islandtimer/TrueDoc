Collection, set and memorabilia

are defined as:

‘collection’ means a set of objects, specimens, writings, and the like, gathered together and which collectively have a special value above that of the items individually if separated;

‘set’ is a number of things customarily used together or forming a complete assortment, outfit, or collection such as a set of dishes;

• 'memorabilia' are things saved or collected as souvenirs.
