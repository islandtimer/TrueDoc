The results of section 3 (p. 25) for linear equations enable us to express the inverse transformation by the formulae

$$x = a'x' + b'y' + c'z'  x = a'x' + b'y'$$
$$y = d'x' + e'y' + f'z'  y = c'y' + d'y'$$
$$z = g'x' + h'y' + k'z'$$
$$\quad \text{or}$$

in which $a', b', \dots$ are certain expressions formed from the coefficients $a, b, \dots$ . Because of the uniqueness of the solution, the original equations also follow from these latter. In particular, from $x = y = z = 0$ it follows that $x' = y' = z' = 0$ , and conversely.

The characteristic geometrical properties of affine transformations are stated in the following theorems.

(1) In space the image of a plane is a plane; and in the plane the image of a straight line is a straight line.

For by section 1 (p. 9) we can write the equation of the plane (or the line) in the form

$$Ax + By + Cz + D = 0 \text{(or} \quad Ax + By + D = 0\text{).}$$

The numbers $A, B, C$ (or $A, B$ ) are not all zero. The co-ordinates of the image points of the plane (or of the line) satisfy the equation

$$A(a'x' + b'y' + c'z') + B(d'x' + e'y' + f'z')$$
$$+ C(g'x' + h'y' + k'z') + D = 0$$
$$\text{(or} \quad A(a'x' + b'y') + B(c'y' + d'y') + D = 0\text{)}$$

Hence the image points themselves lie on a plane (or a line), for the co-ordinates

$$A' = a'A + d'B + g'C  \left(\text{or} \quad A' = a'A + c'B\right)$$
$$B' = b'A + e'B + h'C  B' = b'A + d'B$$
$$C' = c'A + f'B + k'C$$

of the co-ordinates $x', y', z'$ (or $x', y'$ ) cannot all be zero, otherwise the equations

$$a'A + d'B + g'C = 0  \left(\text{or} \quad a'A + c'B = 0\right)$$
$$b'A + e'B + h'C = 0  b'A + d'B = 0$$
$$c'A + f'B + k'C = 0$$

would hold, and these we may regard as equations in the unknowns $A, B, C$
